# 知返 · Zhifan

![知返](icon.png)

**整卷进，分题出。**

知返是一个 AI 驱动的个人错题本 HarmonyOS 应用。拍一整份卷子，AI 自动分题、识别题干和选项、读学生作答与草稿，找出所有错误，并生成复习优先级；今日复习计划由独立规划任务生成。

与市面上其他错题本软件最大的不同是，AI 能力是知返的地基，而不是装饰。你可以上传试卷、答题卡甚至草稿纸，AI 会根据你的做题痕迹分析错因、划定复习优先级、生成每日复习清单。

同时，知返支持选题导出、复习清单和试卷的一键导出，生成适合复习重做的 PDF 文档。

> 当前仓库只发布无签名 HAP 二进制，暂不包含源码。

## 功能

- 一次拍 1–6 页整卷
- 两轮 AI 入库
  - 第一轮：分题、完整题干、选择题选项、作答与草稿
  - 第二轮：全部错因、题目类型、基础/中档/较难、掌握度、优先级
- 今日计划独立生成，不再由第二轮分析顺带输出
- 入库前确认：重命名试卷、编辑学科、选择试卷类型、填写来源
- 试卷类型统一：期末、期中、模拟、单元、作业、其他
- 今日复习：按 AI 优先级排列
- 错题页
  - 整卷视图 / 题目视图
  - 日期、学科、知识点、错题/对题、题目类型、难度、优先级筛选
  - 高等数学知识点树，默认收起
  - 题目卡片左滑菜单：恢复推送 / 取消推送、删除
- 题目详情
  - 题干、你的作答与草稿、标准答案、解答过程、归档错因
  - 打开题目时才按需生成答案
  - 长答案、长题干折叠
  - 追问页，可让 AI 修正归档错因
  - 标准答案可重新生成
- 追问页题目框可折叠，上滑自动收起
- 公式渲染修复：`cases` 多行、`\[...\]`、`\(...\)` 和常用符号
- 删除单题 / 整卷，级联清理错因、追问、复习状态和计划引用
- 多选导出 PDF：一页两栏、一栏两题、不含答案，生成后调用系统分享
- 今日 / 整卷详情一键导出
- 平板横屏适配：首页、错题页宽屏布局，相机 4:3 预览

## 运行环境

| 项目 | 要求 |
|---|---|
| 系统 | HarmonyOS 6.1.1 及以上 |
| API | 24 |
| 设备 | 手机 / 平板 / 2in1 |
| 网络 | 需要访问 DeepSeek API |
| 权限 | `ohos.permission.INTERNET` |

HAP 内置的本地公式渲染依赖 arm64-v8a，主要面向 HarmonyOS 手机和平板。

## 首次使用

1. 安装并打开知返。
2. 进入「设置」。
3. 填写 DeepSeek API：
   - API Key
   - 模型名：`deepseek-flash` 或 `deepseek-v4-pro`
   - API 地址：`https://api.deepseek.com/chat/completions`
4. 回首页「拍整卷」。
5. 等两轮 AI 完成。
6. 在「确认入库」页改好名称、学科、类型、来源。
7. 打开题目时才会加载标准答案。

模型名必须填 API ID，不要填控制台显示名，否则会 HTTP 400。

## 签名说明

这是无签名 HAP。可以这样处理：

### 方式 A：DevEco 自动签名

1. 用 DevEco Studio 打开一个空的 HarmonyOS 工程。
2. 把 HAP 放进工程，或使用 DevEco 的签名工具。
3. 登录华为开发者账号。
4. 使用「自动生成签名」。
5. 连接设备后重新签名安装。

### 方式 B：已有证书手动签名

使用 HarmonyOS SDK 的 `hap-sign-tool.jar`，配合：

- `.p12` 密钥库
- `.cer` 调试/发布证书
- `.p7b` Profile

重新签名后再安装。

> 调试 Profile 需要包含目标设备的 UDID。一个调试 Profile 最多绑定 100 台设备。

## 数据与隐私

- 应用数据保存在本机 SQLite。
- 卷子图片复制到应用沙箱。
- API Key 只保存在本机。
- 没有知返账号，没有知返服务端。
- 图片和题目会发送到你自己配置的 DeepSeek API 做识别和分析。
- 卸载应用会删除本地数据；当前版本没有云同步和自动备份。

---

## 已知限制

- AI 识别手写、反光、跨页大题时仍可能出错。
- 公式渲染对部分少见 LaTeX 命令不完美。
- PDF 固定一页四题，超长题干会裁切。
- 旧数据没有 AI 三档难度时回退为“中档”。
- 没有云同步、自动备份和手动改题。
- 二进制仓库暂不提供源码。
