# 知返 v1.1.0 更新日志

发布日期：2026-11-21

这一版把「拍整卷 → AI 分题 → 错因入库 → 打开题目看答案 → 追问修正错因」这条主链路收稳，并补上平板适配。

## 新增

- 平板横屏适配
  - 首页、错题页按宽屏居中布局
  - 相机预览在平板横屏下改为 4:3，不再被竖屏比例拉黑或溢出
  - 相机顶部与底部控件在宽屏下收窄，不再贴边
- 相机页支持拍照、相册、PDF 导入
- 错题页支持「题目 / 整卷」双视图
- 题目卡片左滑菜单：恢复推送 / 取消推送、删除
- 筛选支持学科、知识点、作答结果、题目类型、难度、试卷类型
- 高数知识点目录支持展开 / 收起
- 题目详情：
  - 答案与解答过程统一折叠
  - 题干过长折叠
  - 字号整体下调
- 追问页：
  - 回复字号下调
  - 题目框缩小并支持折叠
  - 追问列表上滑时自动收起题目
- 公式渲染修复：
  - `cases` 多行不再挤成一行
  - `\[...\]`、`\(...\)` 统一转换为 `$...$`
  - 不等号、无穷、箭头、点乘等符号恢复正常
- 每日计划独立生成
  - 第二轮只做错因分析
  - 今日计划由独立规划任务生成，避免空计划占住今日页

## 优化

- Prompt 重构到 v4
  - `RECOGNITION_SYSTEM_PROMPT`
  - `ANALYSIS_SYSTEM_PROMPT`
  - `ANSWER_SYSTEM_PROMPT`
  - `FOLLOW_UP_SYSTEM_PROMPT`
  - `PLAN_SYSTEM_PROMPT`
- 第一轮识别不再要求知识点，避免和 schema 冲突
- 第二轮不再排今日计划，职责拆分更清楚
- 追问发现错因不准确时，必须通过 `errorPatches` 修改归档错因
- 情绪回应只允许写在追问的 `answer` 字段内
- examType 统一为：期末、期中、模拟、单元、作业、其他
- 旧「月考 / 真题」数据自动迁移为「其他」

## 修复

- 追问里显示字面量 `result.answer`
- 题目详情和追问里公式被拼成一行
- 入库页「确认入库」等标题乱码
- 筛选里的「基础 / 中档 / 错题 / 对题」乱码
- 知识点目录三角、整章、勾选说明乱码
- 题目卡片左滑菜单跑到右滑
- 答案框只折叠答案、不折叠解答过程
- 保存整卷时空计划覆盖当天计划

## 安装

- 系统：HarmonyOS 6.1.1 / API 24
- 安装包：`entry-default-signed.hap`
- SHA-256：

```text
B19F48EA034A94069D9F5B9D1DDB25C2B04FAC8E09FBA69B4C2D909BC4868473
```

首次使用：

1. 打开「设置」，填写 DeepSeek API Key、模型 ID、API 地址
2. 回到「今日」，点「拍照」或「开始拍整卷」
3. 拍完点「开始 AI 分析」
4. 确认识别结果后入库

## 已知限制

- 需要自备 DeepSeek API Key，应用不内置 Key
- 所有数据只存在本机，没有云端同步
- API Key 目前存在应用私有 Preferences，未接入 HUKS 加密
- 当前 HAP 使用 debug 签名，正式分发前需要换 release 签名
- 相机需要系统相机权限
- AI 返回仍可能受模型能力、图片清晰度和网络影响
